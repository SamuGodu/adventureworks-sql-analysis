# AdventureWorks SQL Practice

This repository contains SQL practice exercises and analysis using the Microsoft AdventureWorks sample database.

The exercises are based primarily on the LearnSQL AdventureWorks beginner exercises:

## Purpose

The goal of this repository is to:

- Improve SQL querying skills
- Practice real-world business scenarios
- Develop analytical thinking using SQL
- Learn database exploration and schema understanding
- Build portfolio-ready SQL documentation and projects

## Database Overview

AdventureWorks is a sample OLTP database created by Microsoft that simulates a bicycle manufacturing company called AdventureWorks Cycles.

The database includes multiple schemas such as:

- HumanResources
- Sales
- Production
- Purchasing
- Person

These schemas provide realistic business data for practicing:

- Filtering
- Sorting
- Aggregations
- GROUP BY
- JOINs
- Subqueries
- CTEs
- Window functions
- Business reporting queries

## Current Focus

Part 1 focuses on single-table SQL queries, including:

- Basic SELECT statements
- Filtering data with WHERE
- Sorting with ORDER BY
- Aggregations
- DISTINCT values
- Calculated columns
- Basic data exploration
